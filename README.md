# 📖 About the Project

**Shree Mauli Restaurant** is a modern, responsive restaurant website designed to provide customers with an engaging online experience.

The project showcases a premium restaurant interface along with an **AI-powered chatbot** that helps visitors instantly get restaurant information, menu details, timings, location, and answers to frequently asked questions.

The goal of this project is to combine modern frontend development with AI to improve customer interaction and enhance the restaurant's digital presence.

# 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/amanpawar2004/Shree-Mauli-Restaurant-Website.git
```

### Move into Project

```bash
cd Shree-Mauli-Restaurant-Website
```

### Install Packages

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Open

```text
http://localhost:5173
```
